# IET Placement Insights Backend
This repository is the code for IET Placement Insights Backend Part
The Tech Stack Used is : 
1. Node.js
2. Express
3. MySQL
## Steps to Run Backend
1. Clone the repository.
2. Create a .env file in the cloned folder.
The credentials required to be their in .env are : 
EMAIL_ID = YOUR EMAIL ID 
PASSWORD = YOUR PASSWORD
DATABASE_USER_NAME = YOUR DATABASE USER NAME
DATABASE_PASSWORD = YOUR DATABASE PASSWORD
DATABASE_HOST = YOUR DATABASE HOST
DATABASE_NAME = YOUR DATABASE NAME
STUDENT_PORTAL_BASE_URL = http://localhost:5173
ADMIN_PORTAL_BASE_URL = http://localhost:3000

3. Then to initialize the database go to SQL folder and then run database.js.
    Query : node database.js
4. Then go to the server folder and run server.js file
    Query : node server.js
to start the server.
